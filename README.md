# Ozal & Rusala

Локальный свадебный сайт-приглашение: 14 ноября 2026, 18:00, Villa Барвиха 135.

## Предпросмотр

Из папки проекта запустите `npm run dev` или `python3 -m http.server 4173 --bind 127.0.0.1`, затем откройте http://127.0.0.1:4173.

Сайт статический: HTML, CSS и JavaScript. Установка зависимостей и сборка не требуются. Шрифты, фотографии и орнаменты хранятся локально. Исходные фотографии в `assets` сохранены, сайт использует WebP-копии в `assets/photos`.

Оформление: изумрудный бархат, атласные драпировки, светлая свадебная полиграфия, перчатки и белые цветы. Тема находится в `velvet.css`, оптимизированная графика и промпты генерации — в `assets/velvet`.

## Изменения

- Тексты, дата, место и ссылка карты — `index.html`.
- Дата обратного отсчёта — константа `WEDDING_DATE` в `script.js`; время указано с часовым поясом Москвы (+03:00).
- Цвета и оформление — переменные в начале `style.css`.
- Раскрытие конверта — CSS-анимация длиной 7,2 секунды: после короткой паузы сургучная печать снимается, затем медленно открывается клапан и плавно выезжает сердце. При уменьшении движения сразу показывается открытая композиция без печати. Тиснение и сургуч выполнены локальными SVG.
- Руки видны на закрытом конверте и плавно исчезают с 1,65 до 3,25 секунды, до появления открытки. При уменьшении движения они скрыты сразу.

## Публикация

Для обычного статического хостинга достаточно загрузить `index.html`, `style.css`, `velvet.css`, `script.js` и каталог `assets` (исходные JPG можно исключить).

После выбора домена укажите абсолютный URL изображения `assets/social-preview.jpg` в метатеге `og:image`, добавьте `og:url` и canonical. Превью для мессенджеров станет доступно после публикации на доступном им адресе.

Шрифты Cormorant Garamond и Pinyon Script распространяются по SIL Open Font License; тексты лицензий находятся в `assets/fonts`.
